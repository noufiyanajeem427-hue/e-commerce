# Ecommerce Shop Owner

This project contains the starter structure for an ecommerce shop owner dashboard.

## Folder Structure

- `public/`
- `src/`
- `src/components/owner/`
- `src/context/`
- `src/pages/owner/`
- `src/styles/`
- `src/utils/`

## Getting started

```bash
npm install
npm start
```
